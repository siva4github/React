## Project Overview

`react-essentials` is a small starter that uses Vite and React (configured in this repository for React 19). It's useful for experimenting with modern React features and fast local development using Vite's dev server.

## Prerequisites

- Node.js (recommended v18 or newer)
- npm (comes with Node) or yarn/pnpm

## Getting Started (react-essentials)

1. Clone the repository:

   git clone https://github.com/siva4github/React.git

2. Change to the example folder:

   cd React/react-essentials

3. Install dependencies:

   npm install

4. Start the dev server:

   npm run dev

5. Open your browser at http://localhost:5173 (Vite's default) to view the app.

## Available Scripts

In the `react-essentials` folder the following npm scripts are available (defined in `package.json`):

- `npm run dev` - Start the Vite development server
- `npm run build` - Build the production bundle with Vite
- `npm run preview` - Locally preview the production build

## Project Structure

- `react-essentials/` - Vite + React starter
  - `index.html` - App entry HTML
  - `src/` - Application source (React components & entry)
  - `package.json` - Project metadata and scripts
  - `vite.config.js` - Vite configuration
  - `package-lock.json` - Exact dependency tree (generated by npm)
